## Gotchas / worked examples
The current Foundry FAQ independently confirms **per-session** charging, reusable in the same thread up to one hour; the retail feed has current global/regional prices, but the deployment-to-SKU mapping must be confirmed. ACA Sandboxes (snapshot-capable VM tiers), Dynamic Sessions and Foundry sessions are distinct products/meters.
For **ACA sessions**, 8,800 actually billed session-hours × $0.03 = **$264**, plus inference. This is a unit illustration, not 50×4/8 capacity: size and duration/rounding need validation; arbitrary eight-hour Foundry sessions violate its timeout. One billed session-hour is $0.03 on the verified ACA SKU. Retained snapshots/100 GiB egress aren't established capabilities of the interpreter. See `patches/azure-container-apps.md`; existing providers not rewritten.
One qualifying regional EP session is $0.033 plus model tokens even for a short task; do not bill it as $0.033 times seconds/3600. See [hosted agent resource pricing](azure-foundry-agents.md) for the separate VM regime.
