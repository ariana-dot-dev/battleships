## Gotchas
- Container memory is binary GiB. Tokens are additional. Concurrent containers each incur their own charge; reusing an active container avoids unnecessary creation. Code Interpreter expires after 20 minutes without use; files must be downloaded before expiry. These are lifecycle rules, not proof of a guaranteed long-lived machine. [Interpreter guide](https://developers.openai.com/api/docs/guides/tools-code-interpreter)
- Agents API hosted environments have a different lifecycle: keep-alives between turns; deletion possible after an hour without activity/keep-alives. Standard container pricing still applies; no inference that this is a one-hour $0.03 session. [Hosted environments](https://developers.openai.com/api/docs/guides/agents-api/environments/openai-hosted)
- Codex allowance depends on task/model/context. Published local-message ranges are not cloud-task quotas. API-key access to Codex CLI/SDK does not buy Codex cloud features. Credit top-ups extend eligible plan usage; no reliable fixed cloud-task price or CPU-hour exchange rate established. [Codex pricing](https://learn.chatgpt.com/docs/pricing)
- File-search storage is retrieval storage, NOT general snapshot storage. Do not apply it to retained sandbox files.
## Worked examples / estimator treatment
Standard workload is 8,800 worker-hours (50 × 8 × 22). Under the **20-minute block reading**, continuously used 16 GiB containers cost 26,400 blocks × $0.48 = **$12,672 compute-only**. One 16 GiB container used for 20 minutes costs $0.48 plus tokens. This is not a validated 4-vCPU/8-GiB substitute: CPU is unknown, chosen RAM is 16 GiB, session renewal and eligible minute billing can change cost, and 50-way quota is unverified. Hypothetical prorating of that tariff gives $1.44/hour, but this is a derived rate, not proof of eligible-minute billing.
Codex cloud: 8,800 hours cannot determine token/credit consumption or number of task starts; normalized price = null. A developer paying Plus $20 has an allowance, not 176 guaranteed VM-hours. Snapshot retention (50 GiB) and 100 GiB egress costs/capability are null.
