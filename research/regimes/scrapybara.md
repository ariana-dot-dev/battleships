# Scrapybara: pricing regimes (as of 2026-09-28) — DISCONTINUED
Scrapybara sold virtual desktops for agents: Ubuntu, a browser, and Windows 11 in early access via `client.start_windows()`, with computer-use actions and interactive streaming. The homepage now reads "Scrapybara built computers for agents. Now we're building Capy." The desktop service sunset was announced for 2025-10-15. The docs site is still online but the service is not sold.
